# Blackjack Game

A simple Blackjack game made with HTML, CSS and JavaScript.

## Features
- Play against the dealer
- Hit and Stand
- Random cards
- Blackjack detection
- Ace handling
- Main menu with age check

## Built With
- HTML
- CSS
- JavaScript

## About
I made the basic version of this game during a JavaScript course on Scrimba.

Later, I added a main menu, age check, dealer and more game features.

These were my own ideas, but I also used AI to help me with the code.

I am still working on this project.
